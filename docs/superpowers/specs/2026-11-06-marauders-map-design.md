# Карта мародёров — дизайн (одобрено владельцем 2026-11-06: «Одобряю.»)

Задача Notion 40a13e60-bc8d-8163. Запрос владельца дословно — в локальных заметках автора (в репозиторий не входит).

## 1. Открытие и что на карте (подтверждено владельцем 2026-11-06: «всё верно»)

- Где: чаще дома на диване; иногда в дороге/аэропорту — там, где есть интернет. Без интернета —
  последняя загруженная местность (догадка оркестратора, не опровергнута).
- Открытие: роза ветров (круг с крестом) — в любой вселенной. Для мира Поттера ещё клятва мародёров
  в любой формулировке и переводе: «люди могут по-разному помнить, у людей мог быть разный перевод»
  (владелец 31.10). Страницу читает LLM тем же чтением, что и ответ дневника, и решает, клятва ли это;
  опора — ключевые слова «замышляю», «шалость», «клянусь» / «solemnly swear», «up to no good», хватает
  любой их узнаваемой части, не фразы целиком.
- Мир Поттера — любая персона из вселенной Гарри Поттера, включая встроенную «Методов». Признак
  отмечается один раз при генерации персонажа; для такого мира название — «Карта мародёров», открывашка
  и закрывашка — канонические (не генерируются).
- Закрытие: «Шалость удалась» / «Mischief managed» или та же роза.
- Центр: самая точная доступная точка. GPS и акселерометра на PW2 нет (проверено 31.10,
  /proc/bus/input/devices). Wi‑Fi скан есть (wpa_cli scan_results) → BeaconDB; не нашлось — IP (город).
  Точность BeaconDB на сетях владельца проверена 2026-11-06: скан Wi‑Fi с Kindle (5 сетей) → BeaconDB
  accuracy 34 м; точка по IP — в ~0,9 км от неё.
  Точка по IP (город) не заменяет сохранённую точку по Wi‑Fi в том же городе: дома разовый отказ BeaconDB
  не переносит карту в центр города.
- Сдвиг меньше экрана — карта та же, чуть сдвигается.
- Масштаб: несколько улиц; поле — экран + по полэкрана с каждой стороны.
- Рисунок: настоящие улицы и дома из OpenStreetMap (Overpass, доступ с Kindle проверен 31.10),
  в стиле пергамента своими силами; атрибуция OSM.
- Подписи зданий — на языке вселенной (школа → «Класс трансфигурации», храм → «Часовня»,
  паб → «Дырявый котёл»); словарь «тип здания → место во вселенной» генерируется один раз
  вместе с персонажем.

## 2. Персонажи и следы (подтверждено владельцем 2026-11-06: «всё верно»)

- Кто: персонажи вселенной дневника, состав ротируется между открытиями.
- Сколько: 2–6; на экране ≥1; 0–3 за краем (в запасе по полэкрана), проходят мимо. Маленький экран —
  ~3 видимых + 2 у края.
- Вид: следы с подписью имени.
- Логика: ночь — по домам, по улице сторожа/злодеи, в школе никого; день — больше на улицах, злодеи-
  бандиты могут ходить и днём («если это там бандиты какие-то, они могут и днём нормально ходить»); будни —
  школа/работа, выходные — школа пуста; время года; тип здания (школа, храм), если известен, иначе дома/улицы.
- LLM при открытии не зовётся. При генерации персонажа — один раз: состав ~10–15 героев с ролью
  (ученик/учитель/сторож/злодей) и распорядком. При открытии — чистая функция (час, будни/выходной,
  сезон, тип здания, улица/дом), без сети.
- У каждого героя постоянный дом на карте между открытиями.
- Движение: следы проявляются шаг за шагом частичным обновлением e-ink, шаг ~2–3 с.
- Наклона нет → поле сдвигается пальцем от края или в нижней полосе (решение 2), персонажи заходят из-за края.
- Карта закрывается сама через несколько минут без касаний (батарея).

## 3. Вид карты, другие вселенные, данные (подтверждено владельцем 2026-11-06: «всё верно»)

- Карта — на весь экран вместо страницы дневника. Улицы и дома — тушью по пергаменту: тонкие линии,
  подписи «от руки». Готовых картинок не берём — рисуем сами из линий (векторно, мало места, быстро).
- Появление: линии проступают постепенно, как чернила, потом появляются следы.
- Закрытие («Шалость удалась» / роза) — карта гаснет, возвращается страница дневника.
- Другие вселенные: роза открывает карту везде. Своя фраза-открывашка, фраза-закрывашка и название
  карты («Карта Средиземья») генерируются один раз вместе с персонажем; для мира Поттера — канонические
  (раздел 1).
- Генерируется с персонажем одним разом: признак «мир Поттера», название карты, фразы открытия и
  закрытия (кроме мира Поттера), словарь
  «тип здания → место во вселенной», состав героев с ролями и распорядком.
- Местность: улицы и здания вокруг точки — OpenStreetMap при первом открытии, хранится на Kindle
  (ожидание — десятки КБ, ASSUMPTION); сдвиг больше экрана — догрузка куска.
- Без интернета — последняя сохранённая местность. Первое открытие без интернета — пустой пергамент с
  надписью в духе вселенной («карта пока не видит, где ты»), без поломки.

## Решения оркестратора по проверке спеки (владелец может поправить)

1. Персона «Методов» (встроенная; владелец 31.10: «на Kindle оставь Волдеморта из «Методов»»). Сейчас
   у неё нет генерируемых разделов вовсе (persona.lua:15 «генерировать нечего»; controller.lua:253-254 —
   у встроенной частей нет, _gen_next → nil). Для неё один раз генерируются ТОЛЬКО данные карты (словарь
   зданий, состав героев «Методов» с ролями и распорядком) по её миру; её персона и промпт не меняются.
   Уточнение 2026-11-06 (по плану): текст персоны «Методов» не меняется ни на байт; в инструкцию формата
   ответа добавляется только блок (ключ `"map"`) — без него клятву не прочитать тем же
   чтением страницы (решение 3). Снимок промпта без этого блока прежний.
   Формат данных карты — один для всех персон. Как встроить в генерацию — решает план.
2. Ввод на карте: каждое касание сейчас — чернила (riddle_diarywidget.lua:4-6). На карте сдвиг поля —
   владелец 2026-11-06: «Давай этот сантиметр, как ты говоришь, но ещё плюс сделаем снизу область
   сантиметра два для того, чтобы положить палец, и пока не оторвал, это будет двигать карту». То есть:
   (а) штрих, начатый в полосе ~1 см у любого края экрана, — сдвиг поля по направлению штриха;
   (б) нижняя полоса ~2 см — «тачпад»: палец лёг в неё — пока не оторван, его движение тащит карту.
   Касания в этих зонах — не чернила. Короткий прямой штрих в середине — чернила, как и всё остальное
   (крест розы и буквы «Шалость удалась» сдвигом не считаются). После паузы страница
   штрихов: роза распознаётся локально → закрыть; иначе — чтение LLM, ключевые слова «шалость удалась» /
   «mischief managed» → закрыть. Без сети фраза не закрывает — закрывает роза и автозакрытие.
3. Страница с открывашкой (роза или ключевые слова) — не запись дневника: Реддл не отвечает, в память и
   историю не ложится; вместо ответа открывается карта. После закрытия — чистая страница дневника.
   Роза открывает сразу (локально); фраза — после чтения страницы LLM (нужна сеть), так же долго, как
   ответ дневника. «Несколько секунд» и «без LLM» (цели, анти-цели) — про построение карты после
   распознавания, не про чтение фразы.
4. Запечатанный дневник (seal): карта открывается только при открытой печати — проверка после печати.
5. Центр только по IP (город): владелец 31.10 дословно: «IP нам даёт возможность получить какую-то
   локацию. Это уже неплохо» — карта строится по IP-точке как есть. Точность BeaconDB на сетях владельца
   до плана проверяет тестер живым запросом с Kindle (проверено 2026-11-06, раздел 1).

## Зачем

Дневник Реддла — магический артефакт; карта мародёров — второй артефакт той же вселенной, который
«оживает» на реальной местности вокруг владельца. Ценность — ощущение живого волшебства: знакомые
улицы, по которым ходят герои вселенной, ведущие себя правдоподобно для времени суток и дня недели.

## Цели

- Открыть карту жестом (роза) или фразой вселенной и закрыть так же.
- Показать реальную местность вокруг самой точной доступной точки в стиле вселенной.
- Показать 2–6 подписанных героев, правдоподобно расставленных и двигающихся.
- Работать быстро и без сети после первой загрузки местности; LLM для построения карты не звать
  (фразу-открывашку читает то же чтение страницы, что и ответ, — решение 3).
- Работать для любой вселенной дневника, не только Поттера.

## Не цели

- Точная навигация, маршруты, поиск мест.
- Реальная физика наклона (датчика нет).
- Скачивание чужих картинок/тайлов карт.

## Анти-цели (провал, даже если «работает»)

- Карта, которая строится дольше нескольких секунд после распознавания открывашки или съедает батарею,
  лёжа открытой.
- Герои в нелогичных местах (школа ночью, все дома в будний полдень).
- Падение дневника при отсутствии сети, гео или данных карты.
- Карта, которая выглядит как обычная навигационная, а не как артефакт вселенной.

## Ограничения

- Kindle PW2: e-ink, 8bpp ч/б, без GPS и акселерометра; KOReader-плагин на Lua (luajit).
- Сеть: свой https через luasec (verify="none"); системный curl не годится. Вызовы — в дочернем worker
  по одному, бюджеты 4–30 с (разведка кода 31.10).
- Почерк → текст только через LLM-vision (локального OCR нет); сырые штрихи страницы доступны
  (`self.page.strokes`) — роза распознаётся локально по штрихам, до LLM.
- Картинки — только свои (правило владельца: локальные файлы, без хотлинков); OSM — с атрибуцией.
- Генерация сеттинга уже есть («чей это дневник», persona.lua) — карта добавляет туда свои секции.

## Оставлено исполнителю (решает план)

- Алгоритм распознавания розы по штрихам и порог уверенности.
- Формат хранения местности и словаря, кэш и инвалидация.
- Точная формула расстановки и шаг анимации в пределах «2–3 с».
- Таймаут автозакрытия («несколько минут»).
- Как именно рисовать пергамент (линии, шрифт подписей) в пределах 8bpp.
