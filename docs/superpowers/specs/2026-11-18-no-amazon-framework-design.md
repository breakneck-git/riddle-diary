## Зачем

Владелец (2026-10-25): «там весь мусор амазоновский отсутствует». Цель — освободить память
и убрать оболочку Amazon из-под дневника. Объём владелец сузил (2026-11-18): на вопрос
«хватит остановить оболочку Amazon?» — «подойдет».

## Цели и границы

- Цель: при обычной загрузке Kindle оболочка Amazon (framework) остановлена, пока работает
  KOReader с дневником; память освобождена (замер до/после).
- Не цель: управление устройством знаками пером, своя оболочка, отказ от KOReader.
- Анти-цель: Kindle, который не загружается или не возвращается без ssh/USB; потеря сети,
  подсветки, сна или зарядки по USB.

## Подходы

- **А (выбран владельцем 2026-11-18, «ок»).** Автозапуск `/etc/upstart/riddle-koreader.conf`
  остаётся как есть (`start on framework_ready`, пауза, файл-запрет `/mnt/us/riddle/no_boot`),
  меняется только запуск KOReader: штатный режим KOReader «без оболочки» вместо `--kual`.
  Выход из KOReader возвращает оболочку Amazon. Системные задания Amazon не трогаем.
- Б (отклонён). Отключить запуск оболочки Amazon при загрузке. Быстрее загрузка, но правка
  системных заданий Amazon: падение KOReader при старте = чёрный экран, возврат только по
  ssh/USB.

## Решено

- Правку на Kindle (`/etc/upstart`) делает сисадмин; порядок восстановления — как в спеке
  2026-10-22 «Запуск и выход» (копия в `/mnt/us/riddle/backup/`, файл-запрет, холодная
  перезагрузка).
- Перезапуск KOReader деплоем (выход 85 → `koreader.sh` перезапускает на месте) оболочку не
  поднимает; запасной путь `tools/deploy.sh` (KOReader не запущен) тоже должен стартовать
  без оболочки.
