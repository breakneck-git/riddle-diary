# Печать: графический ключ — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** заменить слово-печать графическим ключом. Печать закрывает данные пользователя, а ИИ отвечает всегда;
правила печати задаются в конфиге.

**Architecture:**
- Состояние печати — один модуль `riddle/seal.lua`, единственный писатель — контроллер.
- Данные отсекаются в одной точке — `Controller:_open_context`.
- Ключ сравнивает с образцом новая чистая функция `riddle/glyph.lua` (облако точек на `riddle/pen.lua`). Образец
  пишет сам дневник в режиме «задать ключ».

**Tech Stack:** Lua / LuaJIT, KOReader plugin API, тесты `tests/run.sh` (раннер `tests/t.lua`).

**Spec:** `docs/superpowers/specs/2026-11-20-seal-key-design.md`

Пути кода — от `plugin/riddlediary.koplugin/` (`R/` = `riddle/`). Одиночный прогон спеки:

```bash
LUA_PATH="plugin/riddlediary.koplugin/?.lua;tests/vendor/?.lua;tests/?.lua;;" luajit tests/<x>_spec.lua
```

## Global Constraints

- **По умолчанию печати нет.** Нет таблицы `seal` или в ней нет ни одного правила — данные доступны всегда.
- **Правила:** `key` (bool), `minutes` (целое ≥ 1, от последней записи), `on_sleep` (bool), `remember` (bool, по
  умолчанию `true`), `off` (bool).
- **Битый конфиг — печать закрыта**, ключ её не открывает, в лог `riddle: seal config invalid: <причина>`.
- **Образец ключа:** `/mnt/us/riddle/seal_key.lua`, пишется только через `file.write_atomic` (`R/file.lua:18`).
- **Закрытая печать:** в `messages` нет ни памяти, ни лора, ни знаний, ни задач. Ответ модели показывается.
- **Счётчик просьб о данных:** 5 за 10 минут, затем фиксированная фраза из `R/texts.lua`.
- **В лог не идут** текст записи, штрихи и образец; исключение — devmode, как сейчас (`R/controller.lua:1021-1024`).
- **Коммиты** — в `main` клона, без push. `tests/run.sh` зелёный после каждой задачи.

## Review Focus

1. **Ответ, собранный при открытой печати, приходит после её закрытия** (ключом или таймером). Ожидание: такой ответ не
   показывается, вместо него — первая строка чистой страницы. Тест — задача 6, шаг 1 (ключ) и задача 7, шаг 1 (таймер).
2. **Образец ключа битый или недописан** (FAT, пропало питание). Ожидание: печать закрыта, лог
   `riddle: seal key unreadable`. Режим «задать ключ» не включается: иначе порча файла сбрасывала бы ключ. Тест —
   задача 5, шаг 1.
3. **Часы Kindle прыгнули назад** (NTP, ручная правка). Ожидание: таймер простоя не закрывает печать раньше срока и не
   падает. Тест — задача 7, шаг 1.
4. **Режим «задать ключ» прерван сном или перезапуском между первым и вторым рисунком.** Ожидание: режим начинается
   заново, полуобразец нигде не записан. Тест — задача 5, шаг 1.
5. **Старый конфиг со словом** (`password_variants`, нет `seal`). Ожидание: печати нет, лог `… ignored`. Деплой — только
   после пересборки конфига (spec §3). Тест — задача 1, шаг 1.
